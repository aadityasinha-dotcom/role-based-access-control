# Setup the project

## Step 1:
#### Clone the repository
## Step 2:
#### Create to terminal for backend and frontend
## Step 3:
#### Use `cd frontend` and `cd backend` and run npm install to install dependencies
## Step 4:
#### Edit the port and database in backend/app/config/db.config.js to connect with mongodb
## Step 5:
#### Start the mongodb server locally
## Step 6:
#### User `npm start` in both the terminal to start backend and frontend
## Step 7:
#### Go to http://localhost:3000/ to see the frontend and sign up as admin or user
## Step 8:
#### Then login with your credentials and see the blog posts
